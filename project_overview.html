1. Project Purpose & Core Solution

Background & Value

🎯 Problem Context

Traditional print textbooks and static PDF documents present key engagement challenges:

  • Passive Student Engagement: Static pages lack interactive elements to hold children's focus.
  • Limited Audio/Visual Support: Language learners lack immediate audio pronunciation or visual context.
  • Delayed Feedback: Practice exercises require manual teacher review rather than real-time self-assessment.

🚀 Product Solution

An interactive web application built over digitised textbook pages:

  • Dual-Page Realistic Reader: Simulates physical textbook reading while layering digital hotspots.
  • Multi-Modal Media Integration: Blends visual reading, synchronized audio recitations, and video content.
  • Embedded Gamified Assessment: Includes drag-and-drop matching and a 3D revision board game.

2. Target Audience & Deployment Context

User Experience

👧 Primary School Learners (Ages 7–12)

Designed with large, touch-friendly interactive targets, vibrant visual cards, immediate score feedback, and audio assistance to support self-paced learning and retention.

👩‍🏫 Classroom & Home Learning

Zero-installation browser delivery allows instant use on smartboards, desktop PCs, laptops, and tablets without requiring app downloads or external plug-ins.

3. Key Product Features & Interactive Modules

Feature Architecture
📖

Dual-Page E-Book Reader & Navigation Hub

Simulates a physical book with dual-page view, full-screen toggle, page thumbnail drawer, table of contents, and a keyword search index for fast page jumps.

🧩

Interactive Cultural Drag & Drop Activity (Pages 128 - 129)

A matching matrix where students connect child characters, national flags, native languages, and traditional foods across 8 countries (Canada, Italy, South Africa, Japan, Turkey, Thailand, Australia). Features live score validation.

🎬

Cultural Showcase Video Modal (Page 130)

An embedded video modal illustrating Japanese and Indian cultures, traditional attire, flags, national anthems, and polite greetings (e.g. Bowing vs Namaste).

🎧

Karaoke Audio Recitation with Word Highlighting (Page 135)

Audio player for the poem "The Crayon Box That Talked". Features real-time karaoke text highlighting synchronized with audio playback to assist early readers with word recognition and rhythm.

🎲

"Star Challenge" 3D Digital Revision Board Game (Pages 136 - 137)

An interactive 3D board game that converts unit revision into a game. Includes virtual dice rolling, animated token movements, curriculum trivia (spelling, prepositions, idioms), star rewards, and score tracking.

4. Technical Stack Summary

Technology
Core Technologies:
Next.js 16 (App Router) React 19 TypeScript Tailwind CSS v4 HTML5 Audio / Video APIs
Key Architectural Traits:
  • Client-Side State Management: Responsive UI state updates for modals, reader navigation, and board game logic.
  • Modular Component Architecture: Decoupled modal components allowing easy addition of new textbook units.
  • Zero Backend Dependency: Runs completely client-side for ultra-fast load times and offline/classroom deployment capability.

5. Application User Flow & System Journey

Architecture & Flow
Step 01
Reader Initialization
User opens application; dual-page layout loads page metadata, keywords, and hotspot overlays.
Step 02
Hotspot Triggering
User clicks visual hotspot overlays or bottom bar quick-launchers to activate activity modals.
Step 03
Interactive Module
Modal renders drag-and-drop game, video stream, synchronized audio poem, or 3D board game.
Step 04
Immediate Validation & Feedback
System evaluates answers or game moves, providing real-time visual score updates and encouragement.
Step 05
Navigation & Progress
User closes modal and continues exploring remaining pages via sidebar index or direct search.
